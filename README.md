# Portafolio_EPE1

Portafolio personal desarrollado como parte de la asignatura Desarrollo Web II.
El proyecto presenta información sobre mi formación académica, habilidades, proyectos educativos y experiencia laboral en el área de minería y sondaje.

## Tecnologías utilizadas

- HTML5
- CSS3
- Bootstrap 5
- JavaScript
- JSP (JavaServer Pages)
- SQL Server
- JDBC
- Apache Tomcat
- Git y GitHub
